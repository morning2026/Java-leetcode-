# 动态规划
每一个状态由上一个子状态推导而来
区别于贪心的局部最优
## 完全背包问题
物品有无限个
dp[i][j] = max(dp[i - 1][j], dp[i][j - weight[i]] + value[i]);
dp[i][0] = 0 , dp[0][j] =  dp[0][j] = dp[0][j - weight[0]] + value[0];能放就一直装


## 例题
### 最小花费爬楼梯
0、1不消耗体力
dp[i] = min(dp[i - 1] + cost[i - 1], dp[i - 2] + cost[i - 2];
dp[0] = 0，dp[1] = 0;
### 打家劫舍II
实际上就是第一间和最后一间不能同时偷，给个限制求最大就好
### 打家劫舍III
用数组记录状态，
不偷自己就是最大的左孩子偷不偷，右孩子偷不偷
偷自己就是左孩子不偷右孩子不偷+自己

## 注意
子数组必须连续，子序列不用

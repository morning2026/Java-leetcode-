# 队列
先进先出
Queue<E>：单向队列
Deque<E>：双端队列，直接继承自 Queue
一、出队 / 弹出：pop / poll / pollFirst
1. poll()
   归属：Queue 通用方法
   作用：删除并返回队首元素
   队列为空 → 返回 null（不报错）
   语义：普通队列「从头出」
2. pollFirst()
   归属：Deque 独有
   作用：删除并返回双端队列头部
   空 → 返回 null
   poll() 底层等价于 pollFirst()
3. pop()
   归属：Deque 栈模式专用
   作用：删除并返回栈顶（也是双端队列头部）
   栈 / 队列为空 → 直接抛异常 NoSuchElementException
   语义：栈「弹栈」
   二、入队 / 压栈：offer / push
1. offer()
   归属：Queue / Deque
   作用：从队尾加入元素（队列模式，尾插）
   容量满 → 返回 false，不报错
2. push()
   归属：Deque 栈模式专用
   作用：从队列头部插入元素（头插，模拟栈）
   容量满 → 抛异常
   搭配 pop() 完美实现栈：
   push(头插) ↔ pop(头删)
